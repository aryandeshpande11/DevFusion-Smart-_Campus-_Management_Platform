# Smart Campus Management Platform

## Problem Statement
Problem Statement 1: Smart Campus Management Platform

## Difficulty
Medium to Advanced

## Domain
EdTech, SaaS, Productivity

## Background
Most colleges are still running on a patchwork of tools for basic day-to-day operations — announcements go out on WhatsApp groups, attendance is tracked in separate registers or spreadsheets, event details get lost in email threads, and placement notices are shared through whatever channel happens to be convenient at the time. None of these systems talk to each other, which means students end up missing important updates and faculty end up doing the same work multiple times across different platforms.

The idea here is to bring all of this under one roof. A Smart Campus Platform where students, faculty, coordinators, and administrators can actually work through a single system instead of five different ones.

This isn't meant to be a prototype or a proof of concept — it needs to function like something a college could actually deploy and use. That means real authentication, proper role-based access, working notifications, dashboards that show meaningful data, and a UI that doesn't break on a phone screen.

## Objective
Build a full-stack web application that handles:

- Student Portal
- Faculty Portal
- Event Management
- Attendance
- Placement Notices
- Club Activities

## What Each Module Needs to Do

### Student Portal
Students should be able to log in and see everything relevant to them in one place — announcements, assignments, their own attendance record, upcoming events, and placement notices they're eligible for.

### Faculty Portal
Faculty need a way to post announcements, mark attendance for their classes, put up assignments, and manage whatever event or club responsibilities they're handling.

### Event Management
Covers creating and publishing events, letting students register or RSVP, and keeping some kind of calendar view so people know what's coming up.

### Attendance
Faculty mark it, students can check it. There should be some basic analytics here too — attendance percentage per subject, per student, that kind of thing.

### Placement Notices
Admins or coordinators post placement drives with eligibility criteria and deadlines, students apply, and there's a way to track who applied to what.

### Club Activities
Clubs need their own space to manage membership, post updates, and announce activities without it getting mixed up with general college announcements.

## Things That Need to Be Right, Not Just Working

- Authentication has to be secure, not just a login form that technically works
- Different roles (student, faculty, coordinator, admin) need genuinely different permissions, not just a different landing page
- Notifications should actually reach people, not sit unread in some notification tab nobody checks
- Dashboards need to show something useful depending on who's logged in, not the same generic view for everyone
- The whole thing needs to work properly on mobile, since that's realistically how most students will be using it
